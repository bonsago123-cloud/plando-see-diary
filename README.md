# 잠자리에 드는 시각과 잠들기까지 걸리는 시간

## 1일차에 정한 기준

- 질문: 잠자리에 드는 시각은 잠들기까지 걸리는 시간과 어떤 관련이 있을까?
- 지표 / 단위: 잠들기까지 걸린 시간 / 분
- 계산식: 잠든 시각 − 잠을 자려고 누운 시각. 자정을 넘으면 날짜를 포함해 계산한다.
- 처음 계획 규칙: 1~2일차에는 밤 9시 30분 이전에 잠을 자려고 눕는다.
- 잠든 시각 확인 방법: 다음 날 아침에 기억을 바탕으로 추정하여 기록하고, ‘추정’이라고 표시한다.
- 누락값 처리: 누운 시각이나 잠든 시각을 모르면 누락으로 표시하고, 합계·평균 계산에서 제외한다. 평균의 분모는 유효한 기록 수로 한다.
- 중복값 처리: 같은 수면 기록이 중복되면 한 건만 계산한다.
- 이상값 처리: 날짜·시각 입력 오류를 확인해 수정한다. 실제로 잠들기까지 오래 걸린 기록은 제외하지 않는다.
- 반올림 기준: 시각은 분 단위로 기록하고, 평균은 소수점 셋째 자리에서 반올림하여 둘째 자리까지 표시한다.
- 주 시작 요일: 월요일

## 실제 사용 기록

실제 계획·실행 기록은 사이트의 내 계정에도 저장한다. 날짜와 시각은 한국 시간(Asia/Seoul) 기준으로 적는다. 잠든 시각은 다음 날 기록하며, 추정한 값은 ‘추정’이라고 표시한다.

### 1일차 결과

- 계산: 21:42 − 21:27 = 15분. 사이트 표시 값 15분과 일치한다.
- 규칙 준수: 21:30 이전인 21:27에 누웠다.
- 관찰: 거진 15분 만에 잠든 것으로 추정한다. 딱히 뒤척이거나 잠에 못 들어서 고생한 기억이 없다.
